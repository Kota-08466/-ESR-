# -ESR-
コンデンサの内部構造（陽極面積・陰極面積・電極間距離・封口部高さ・構造）とESRの関係を分析する。

## 分析システム概要
- 陽極面積、陰極面積、陽極面積かつ陰極面積、電極間距離、封口部の高さとESRのを比較する散布図の表示。
- 構造をA（陰極が前）、B（陽極が前）、C（陰極が前でテープ付き）、D（陽極が前でテープ付き）の4種類に分け、さらに容量によるESRの変化と測定データの数を考慮して、記載容量が1μF～47μF、100μ～1000μ、すべてのデータの3つ箱ひげ図を表示する。
- 散布図、箱ひげ図共に耐電圧・耐熱温度・メーカーを選択できる。

## 実行方法

### 1. 必要なライブラリのインストール
Pythonがインストールされている環境で、ターミナルから以下を実行してください。

```bash
pip install streamlit pandas plotly openpyxl
```

### 2. ファイルの配置
以下のファイルを同じフォルダに配置してください。

- `分解ESR解析アプリ_完成版.py`（解析プログラム）
- `分解ESR.xlsx`（解析データ）

### 3. アプリの起動
ターミナルで上記のファイルがあるフォルダに移動し、次のコマンドを実行してください。

```bash
streamlit run 分解ESR解析アプリ_完成版.py
```

ブラウザが自動的に起動し、ESR解析アプリが表示されます。自動で開かない場合は、ターミナルに表示されたURLをブラウザに入力してください。

### 注意事項
- Excelファイルの名前や配置場所を変更すると、プログラムが正常に動作しない場合があります。
- 必要なライブラリがインストールされていない場合は、手順1を実行してください。
